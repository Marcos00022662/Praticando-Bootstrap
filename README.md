# Praticando Bootstrap

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar meus conhecimentos em desenvolvimento web, utilizando HTML5, CSS3, JavaScript e Bootstrap 5. Durante o desenvolvimento, explorei a criação de layouts responsivos, cards, botões, sistema de grid, ícones e janelas modais, além de aplicar estilos personalizados e efeitos visuais. O projeto faz parte da minha jornada de aprendizado em programação e tem como finalidade colocar em prática os conhecimentos adquiridos e desenvolver minhas habilidades na criação de páginas web.
